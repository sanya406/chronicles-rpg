# Chronicles RPG 0.2

Forge 1.20.1 / 47.3.33 / Java 17.

## Что добавлено
- окно персонажа по клавише K;
- уровень, XP и очки навыков;
- 5 характеристик: Сила, Ловкость, Выносливость, Интеллект, Воля;
- прокачка характеристик;
- отдельная ветка из 3 навыков для каждого класса Dungeons & Combat;
- изучение навыков за очки;
- сохранение характеристик и навыков через Forge Capability;
- данные сохраняются после смерти;
- сервер проверяет доступность навыка и наличие очков.

## Классы
forgotten_knight, vagabond, titan, oni_slayer, bounty_hunter, exiled, rogue.

## Управление
K — открыть окно персонажа.

## Сборка
Нужен Java 17 и интернет для скачивания ForgeGradle/зависимостей.

```bat
gradlew.bat build
```

Готовый JAR появится в `build/libs`.

Важно: этот проект подготовлен как исходник. В текущей среде Forge-зависимости не скачивались из-за отсутствия внешнего сетевого доступа, поэтому JAR здесь не компилировался.
